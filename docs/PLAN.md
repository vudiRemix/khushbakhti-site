## 1. Цели

- Гость с телефона за 1–2 нажатия видит меню **на своём языке**: русском, таджикском, английском или китайском.
- Гость в зале может показать официанту выбранные блюда; гость дома может **заказать доставку** через WhatsApp, Telegram или звонок.
- Администратор обновляет меню, цены, фото и наличие блюд **с телефона или компьютера**, без разработчика.
- Переводы блюд делаются **автоматически** при сохранении; администратор только проверяет их.

Вне первого релиза: онлайн-оплата, бронирование столов.

## 3. Автоперевод

1. Администратор вводит блюдо **на русском**.
2. При сохранении сервер отправляет название и описание в **Google Cloud Translation API** на `tg`, `en`, `zh-CN`.
3. Переводы сохраняются со статусом `auto`. На сайте ничего не переводится «на лету».
4. Перевод повторяется, только если русский текст изменился (хеш исходника).
5. Переводы со статусом `manual` автоматически **не перезаписываются**.
6. Если перевода нет, показывается русский текст.
7. **Словарь «не переводить»**: плов, кенча, шурпа, кавурдок, чазза, мошпиёба, девзира — задаются один раз вручную.
8. Интерфейс сайта переводится один раз вручную в `messages/{ru,tg,en,zh}.json`.

## 4. Проверка переводов (выполнено)

Все 25 блюд и тексты интерфейса вычитаны вручную. Главные исправления:

| Было | Стало | Почему |
|---|---|---|
| «Мошпиёба бо қайсӣ» | «Мошпиёба бо **ӯрик**» | урюк (курага с косточкой) по-таджикски — ӯрик |
| «Шӯрбо бо кофта» | «Шӯрбо бо **кӯфта**» | правильное написание |
| «Хомшӯрбои гӯсфандӣ» | «Хомшӯрбо **аз гӯшти гӯсфанд**» | естественнее по-таджикски |
| «Мурғи «Табака»» | «**Чӯҷаи** «Табака»» | цыплёнок — чӯҷа |
| «Боли мурғ» | «**Болҳои** мурғ» | крылышки — множественное число |
| «Қавурдоқ» | «**Қовурдоқ**» | принятое написание |
| «Плов по-самаркандски (девзира)» | «**Девзира по-самаркандски**» | одно блюдо, как подтвердил ресторан |
| «Ҳамаи меню бо акс», «Роҳ» | «Тамоми меню бо аксҳо», «Масир» | точнее по смыслу |
| zh «撒马尔罕抓饭» | «撒马尔罕德夫兹拉抓饭» | добавлен сорт риса |

Оставлено как в меню ресторана (собственные названия): «Чазза», «Кенча», «Мошпиёба», «Наполеон». Перед запуском таджикский всё равно стоит один раз показать носителю языка.

## 5. Стек

| Часть | Выбор |
|---|---|
| Сайт и API | Next.js (App Router) + TypeScript |
| Мультиязычность | Свои словари `src/messages/*.json`, маршруты `/[locale]`, `hreflang` |
| Стили | Tailwind CSS с токенами из `docs/DESIGN.md`; шрифты свои (`public/fonts`) и Google Fonts |
| БД и фото | Supabase (Postgres + Storage); локально — файл `data/store.json` |
| Переводчик | Google Cloud Translation API (ключ только на сервере) |
| Карта | Встраиваемая карта OpenStreetMap / 2GIS по координатам, кнопка «Маршрут» на Google Maps |
| Обновление сайта | On-demand revalidation после сохранения (сайт обновляется сразу) |
| Хостинг | Бесплатный: Netlify (адрес `*.netlify.app`) + Supabase, см. `docs/DEPLOY.md` |

## 6. Модель данных

```
categories            id, slug, sort, is_visible
category_translations category_id, lang, name, status(auto|checked|manual), source_hash
dishes                id, category_id, price_tjs, photo_url, tags[] (new),
                      is_available, sort, updated_at
dish_translations     dish_id, lang(ru|tg|en|zh), name, description,
                      status(auto|checked|manual), source_hash, updated_at
glossary              term_ru, term_tg, term_en, term_zh   -- «не переводить»
tables                id, number, qr_slug
settings              plov_today(bool), hours, phone, address, whatsapp, telegram,
                      instagram, delivery_fee_tjs, lat, lon
profiles              user_id, role(admin|editor)
```

Заказы доставки в базе не хранятся: гость отправляет готовое сообщение в мессенджер ресторана. Безопасность: Row Level Security; запись только для `admin`/`editor`; ключи только на сервере.
